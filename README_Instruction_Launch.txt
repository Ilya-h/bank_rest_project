Инструкция запуска приложения "Системы Управления банковскими картами":

1. Запустить IntelliJ IDEA

2. Проверить в терменале IntelliJ IDEA

docker --version
docker-compose --version
git --version

3. Клонировать репозиторий через git bush или cmd
git clone https://github.com/Ilya-h/bank_rest_project.git
cd bank_rest

5. Запустить Docker

4. Собрать и запустить контейнеры в docker, тоже в терменале IntelliJ IDEA

docker-compose up --build

5. Запустить приложение в IntelliJ IDEA
